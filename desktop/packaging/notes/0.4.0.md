- Reach from anywhere works: your phone reaches Fermix on this computer from any network, with nothing more to install.
- GPT-6.1 Terra is in the model lists.
- Fermix can watch feeds, streams and webhooks, and wake a task when something you asked it to watch for arrives. Turn on Run cues and add sources on the browser setup's Cues tab, with memory on, then restart Fermix.
- Fermix can check in on something you said you would do by a date. Turn it on from the browser setup's Personalization tab, then restart. It needs a chat app such as Telegram to reply in.
- You can also pair a phone from the browser setup's Channels tab.
- Every date and time Fermix gives its model is in the time zone set in Personalization, so something you said this evening is no longer called yesterday.
- When Anthropic credit runs out and a backup provider is set up, the backup answers instead of Fermix stopping.
- A command waits for your yes in chat once a request has read something someone else wrote, such as a web page or an attachment.
